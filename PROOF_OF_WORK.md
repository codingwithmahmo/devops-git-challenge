## Reflection Questions

### Q1: Difference between Git (local tracking) and GitHub (cloud platform)

Git is a version control system that tracks changes locally on your computer. GitHub is a cloud platform that hosts Git repositories remotely, allowing collaboration. Git works offline, GitHub requires internet but enables team sharing and backup.

### Q2: Explain 3 architecture stages: Working Directory, Staging Area, Local Repository

Working Directory: Your actual project folder where you edit files. Staging Area (Index): Files you've marked for commit using 'git add'. Local Repository (.git folder): The committed history stored on your machine before pushing to remote.

### Q3: Difference between git stash pop and git stash apply

'git stash pop' restores stashed changes AND removes them from the stash. 'git stash apply' restores changes but KEEPS them in the stash, letting you apply them multiple times.

### Q4: Difference between git fetch and git pull

'git fetch' downloads remote changes but doesn't merge them into your branch. 'git pull' does both: it fetches AND automatically merges remote changes into your current branch.
